# Changelog

## Initial publication — 2026-10-03

- Community session troubleshooting, with the newer supplied handoff taking precedence.
- English and German getting-started pages and an illustrative walkthrough.
- Windows, macOS and Linux launchers using Python's standard library.
- Hidden API-key input, authentication checks, model discovery and optional chat.
- Automatic selection that skips model IDs containing `embed` unless explicitly overridden.
- Process-scoped client configuration without saving credentials or modifying shell profiles.
- Local HTTP fixture tests and GitHub checks on three operating systems.

See [verification status](docs/verification.md) for the limits of the evidence.
