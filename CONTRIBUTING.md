# Contributing

Useful contributions include confirmed session behavior, clearer instructions, new client examples and fixes to the cross-platform starter.

1. Describe one reproducible problem or improvement.
2. Include OS, Python, LM Studio and cloudflared versions where relevant.
3. State whether you tested it locally, through a tunnel or after a full session reset.
4. Replace personal domains and remove credentials before sharing output.
5. Run `python -m unittest discover -s tests -v` for script changes.

Do not include actual keys, token files, raw environment dumps, complete LM Studio settings, private screenshots or model downloads. Do not post techniques for bypassing host security or usage limits. Documentation fixes should distinguish user observations from documented upstream behavior.

By submitting your original contribution, you agree that it can be distributed under this repository's MIT license. Check that you have permission to share any quoted third-party material.
